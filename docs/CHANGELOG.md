# 更新记录

v3.26.1 更新：宽高、留边、分段宽度和长宽比的滑轨使用固定位置取值。常用尺寸分配更多滑轨空间，Ctrl、Shift 细调仍可用。

v3.26 更新：批量生成可指定起始拼图、分割方式和贴图分辨率，支持固定行列及自动续页。

v3.25.1 更新：扫描版和混合版机位坐标表 PDF 可直接离线提取编号。有文字层时直接读取，扫描页自动 OCR。

v3.25 更新：批量导入可离线识别 PNG/JPG 机位坐标表截图，按表头和同一行的编号、坐标配对筛选。存疑行核对后才可生成。

v3.24 更新：多张拼图在同一预览中纵向排列，可滚动并直接点选邻页。批量按参考字高和纹理尺寸自动分图，导入航图时以机位坐标表和引入线关联为依据。

v3.23.1 更新：尺寸、留边、分段宽度和长宽比改为从当前值相对拖动，固定档位字高仅保留下拉菜单。

v3.23 更新：可从编号清单、航图 PDF、AutoCharts 和 sign_autogen JSON 批量生成地面机位编号。一个工程可保存多张拼图，并批量导出贴图、POL 和槽位索引。

v3.22 更新：标牌、拼图、拾色器、油漆和 POL 的数值设置支持滑块。Ctrl 和 Shift 可逐级细调，拖动时实时预览。

v3.21 更新：标牌支持分别设置左右留边，拼图支持一起拖动整行或整列的对齐分割线。

v3.20 更新：标牌自由尺寸可在毫米与长宽比之间切换。比例模式从自动尺寸补宽或补高，显示计算后的毫米尺寸，并支持组合牌、工程保存、复制粘贴和撤销重做。

v3.19 更新：操作集中到顶部“文件 / 编辑 / 视图 / 标牌 / X-Plane”菜单。预览支持滚轮、加减按钮、100% 和适合窗口，放大后可用中键或空格加左键拖动。新增 X-Plane 开关，新工程默认 PNG 模式，只显示 PNG 导出；开启后显示 POL 设置、PNG + POL 和原有 SVG 导出。开关随工程保存并支持撤销，关闭时保留所有 POL 参数；旧工程自动保留 X-Plane 模式。预览缩放和平移不改变工程尺寸、UV 或导出结果。

v3.18 更新：统一浅色工作区、暖灰侧栏、细线图标、圆角输入框与黑色主按钮。默认窗口 1440 × 890，宽高约为 1:0.618；间距采用 8 / 13 / 21 / 34 / 55 的尺度。布局与分辨率面板默认收起，画布获得更多空间；配色与磨损位于画布工具栏，PNG + POL 位于右上角。按钮悬停、按下、输入框焦点、区域选中与布局展开采用约 180 ms 的缓动，允许中途反向，空闲或隐藏时停止计时，并遵循 Windows 客户区动画设置。配色、油漆、POL 和拾色器共用控件样式。工程与贴图导出格式保持兼容。

v3.17 更新：配色简化为黄色、黑色、白色、红色四类。按图案的原始颜色统一替换，同一种颜色无论用于文字、底色还是边框都同步改变，不再按标牌类型逐项设置。保留单格覆盖、PS 拾色器、实时预览、配色预设和撤销 / 重做。旧工程和 v1 预设保持原外观，改某类颜色时会覆盖旧的类型 / 通用配色中对应原始颜色。

v3.16 更新：顶部改为“类型配色…”，地面及指示牌的方向 / 位置 / 强制指令、地面机位编号、机位号码牌、MAX SPAN、HP、NO ENTRY、机型文字共 12 种类型分别设置颜色。组合牌按各分段类型取色，单格颜色覆盖优先。支持实时预览、PS 拾色器、整套配色预设 `.asscolors` 保存 / 读取，以及撤销 / 重做；类型配色随工程保存，旧工程的统一颜色保留在“通用”项。

v3.15 更新：加入撤销 / 重做按钮和 Ctrl+Z / Ctrl+Y，保留最近 100 步编辑。粘贴、清空、合并、拆分、恢复均分、边界拖动、标牌参数、画布及全局设置均可恢复；一次拖动或一次颜色设置算一步。取消拖动或取消选色不产生记录。界面移除功能介绍和操作教程，仅保留名称、参数、状态和错误。仍为单个 EXE。

v3.14 更新：启动直接进入拼图编辑器，单块标牌也可用 1 行 × 1 列制作。预览格子支持右键“复制标牌 / 粘贴标牌”和 Ctrl+C / Ctrl+V，侧栏底部保留同名按钮。复制类型、内容、尺寸、颜色、分段等完整标牌参数，目标边界、合并结构、隐藏格及全局设置保留。文字输入框内快捷键仍用于普通文字编辑。退出拼图即退出程序，未保存修改会提示保存。

v3.13 更新：按 Codex 浅色界面的方向统一视觉层次。浅灰侧栏使用单色图标与柔和选中背景，白色工作区搭配细边框、圆角输入框和黑色主操作按钮；预览改为浅色棋盘与圆角边界。主窗口、拼图窗口、颜色、POL、油漆和 PS 风格拾色器共用同一套配色与按钮。下拉菜单、键盘操作及高 DPI 仍使用 Windows Forms 基础控件。全部字形、工程数据和贴图导出保持兼容，仍为单个 EXE。

v3.12 更新：界面改为紧凑的 Windows 工具布局。移除品牌横幅、编号卡片和青绿色装饰，使用原生类型列表与标准按钮；缩小标题、内容输入字号及多余间距；预览使用中性灰，选区改为蓝色。拼图工程操作集中在顶部，导出集中在底部“PNG + POL…”。颜色窗口用小色块打开 PS 风格实时取色器。保留单文件发布、工程格式和全部贴图导出功能。

v3.11 更新：改为内含 .NET 10 运行环境的单文件 EXE，启动时直接启用 PerMonitorV2 界面缩放。所有字形与油漆资源内置，无需手动解压、联网或管理员权限。保存工程、PNG + 总 POL 和 PS 风格实时取色器用法沿用 v3.10。旧版本使用的同名 `.exe.config` 不参与新版运行。

v3.10 更新：PS 风格取色器，支持色彩方块、竖向色相条、新旧颜色对比、HSB / RGB / Hex 输入。拖动、输入色值、启用覆盖和恢复继承均实时更新标牌预览；取消拾色器恢复本次选色，取消颜色设置窗口恢复本轮编辑前的全部颜色。

v3.9 更新：支持整张拼图统一颜色和单个标牌独立颜色，分别设置文字 / 箭头、底色、边框 / 分隔线，可使用选色器或 #RRGGBB 色值。POL 可在“实际图案边界”和“分割区域边界”之间切换。颜色、继承关系及边界模式均随工程保存，旧工程保持原颜色和实际图案边界。

v3.8 更新：修复界面在不同 Windows 显示缩放下的尺寸不一致。主窗口、拼图窗口、油漆及 POL 窗口使用统一的缩放基准；切换类型、选中槽位后重新生成的输入框和文字跟随当前缩放；组合牌表格按字体自动调整行高。界面优先使用 Microsoft YaHei UI，缺少时使用系统界面字体。标牌轮廓和贴图像素尺寸仍由工程参数决定。

v3.7 更新：按用户提供的 `Markings_01_轻污渍Sample.psd` 重做油漆材质，直接读取薄漆、顺向刷纹、微颗粒、浅明暗和轻污渍的图层 / 蒙版数据，并按对应混合方式绘制到任意标牌。默认“参考轻污渍”保持完整漆面。增加刷纹强度与参考暖黄开关，方向可用于全部预设。PNG + 单个总 POL、出血及工程保存功能保持。

v3.6 历史更新：加入四套可调油漆预设：轻微粉化、积尘油污、斑驳剥落、车轮擦磨。效果直接烘焙进 PNG，掉漆处透明；全部参数随工程保存。PNG + POL 导出改为直接保存到文件夹，只有一张 PNG 和一个总 POL。

v3.5 更新：实际图案外沿默认四周各留 **2 px 出血**；在 POL 设置窗口可调 0–32 px，0 为紧贴图案。设置随工程保存，旧工程缺少此项时默认 2 px。出血是分区范围向外多留的像素，最多到所在格边界，防止带入相邻格；不会绘制可见线条、扩散颜色或放大图案。留白不足时可增大拼图留白。

v3.4 更新：POL 分区边界取实际字形、底板及边框共同形成的外接矩形，去掉图案外围透明留白。透明底文字按字形外沿取边界，底板或边框存在时包含它们。分区列表的像素尺寸及 POL 中的物理尺寸同步使用图案外沿。

v3.3 更新：一张 PNG 对应一个总 POL，所有有效区域作为该 POL 内的分区。只需设置一个名称和 layer，分区自动跟随合并和边界调整。可直接读取 v3.2 工程，沿用原前缀作为总 POL 名称。

保留 v3.2 的保存、读取、另存拼图工程功能，跨次继续编辑；保存所有标牌内容、嵌套合并、局部边界、分辨率及 POL 设置。

v3.1 更新：相邻区域可合并为一个矩形，也可拆分恢复；直接拖动分隔线调整局部边界，上下行可以使用不同列宽。合并后的像素密度、预览和导出使用实际区域大小。

v3 更新：先设置行列，再点击预览中的槽位编辑；同一张图可以混合全部标牌类型；每格独立内容、尺寸和样式；复制/粘贴槽位；分辨率预设和自定义宽高；按实际字高提示像素密度，并计算建议分辨率。沿用 v2 的平滑矢量字形、自由底板尺寸及 MAX SPAN、HP、NO ENTRY、机型文字。
