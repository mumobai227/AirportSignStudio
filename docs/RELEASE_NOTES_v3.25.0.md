## 直接导入机位坐标表截图

- 「批量生成 → 导入航图或截图」支持 PNG/JPG，使用与 sign_autogen 相同的 PP-OCRv4 识别模型离线运行。
- 保留 0P 表的标题、编号列、坐标列和边线。只接受机位表中与坐标配对的编号；滑行道表和图面上的散落标签不会作为机位清单导入。
- 出现「待核对」或「待补编号」时，请对照原图修正或删除该行，再按原有流程批量生成及自动分页。

盛乐机场两张测试截图的 161 个编号逐项核对一致。8,336 项无窗口检查通过，另以隔离目录中的单文件测试程序验证 OCR 可从包内加载模型及本机运行库。

Windows x64 单文件 EXE 内含 OCR 模型及运行库。发布页同时提供 Windows ZIP、源码 ZIP 和 SHA256 校验文件。
