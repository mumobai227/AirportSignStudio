# 使用指南

## 使用

1. 启动直接进入拼图，展开画布上方“布局与分辨率”设置行列和分辨率。只做一个标牌时设为 1 行 × 1 列。
2. 点击一个预览格子，在左侧选择素材类型，输入内容并调整箭头、字高、边框等参数。
3. 默认点击右上角“导出 PNG…”。需要 X-Plane 时，在顶部“X-Plane → 启用 X-Plane”打勾，主按钮改为“PNG + POL…”。“文件”菜单同步显示可用导出项。输出使用当前画布的精确宽高。

| 素材 | 支持内容 |
|---|---|
| 滑行道地面标志 | 黑底黄字位置标志、黄底黑字方向标志、红底白字指令标志；方向箭头可在侧面或上方 |
| 地面机位编号 | 上、左、右箭头底板；矩形制作备选；可调字距与对比黑边 |
| 滑行道指示牌 | 位置、方向、强制指令牌；最多 6 段，可增删、上移、下移；配对字距和字符宽度按表计算 |
| 机位号码标记牌 | 黄底黑字；可选两行经纬度；牌面随内容自动扩展 |
| 其他地面标志 | MAX SPAN 两行翼展标志、HP 位置识别点、NO ENTRY、黄色机型文字 |

组合牌：双击“内容”单元格输入，或选中后按 F2；类型和箭头通过下拉框选择。输入即时预览。左转箭头放在文字左边，直行及右转箭头放在文字右边；组合次序由列表决定。强制指令牌与方向牌混排会阻止导出，位置牌可以与强制指令牌组合。

字母支持 A–Z、数字 0–9、空格和短横线，自动转为大写并兼容全角输入。牌面字形另有 `/`、`.`、`Ⅰ`、`Ⅱ`、`Ⅲ`；例如可输入 `09 CAT Ⅱ/Ⅲ`。地面编号不使用牌面字体。经纬度用 `N 52 30.2`、`E 114 25.1` 一类文本输入；示例摘自规范，不是项目机场的坐标，程序不自动计算或校验坐标数值。

## 自由尺寸

编辑面板向下滚动可看到“自由尺寸”。宽度、高度单位都是毫米，**0 表示自动**。例如把机位牌的宽度设为 2400、高度设为 1200，再依次输入 21、22、101L，即可得到相同底板尺寸的牌面。字高、字宽保持不变，内容在底板内居中。尺寸过小时会提示所需最小值，不会压扁字形。

滑行道组合牌：选中一行，在“所选分段宽度”设置该段宽度；每段可独立指定。组合牌整体宽度为各段之和，整体高度在“自由尺寸”调整。自定义尺寸属于场景制作参数，并不自动满足规范全部边距要求。

把“自由尺寸”切换到“长宽比”，输入横向宽度与纵向高度的比例，例如 `3:2` 或 `1:2`。程序从自动尺寸出发，沿需要的一边补足留白来达到比例，字形大小保持原样。组合牌以现有分段宽度之和作为起点，需要加宽时将新增宽度均分给各段。预览下方显示计算出的毫米尺寸。留空使用自动尺寸，切回“宽高 / mm”可继续使用之前的毫米值。比例模式随工程和格子复制保留。

## 槽位拼图

1. 启动后直接显示空白拼图网格，也可点击“文件 → 读取工程…”继续已有工程。
2. 展开“布局与分辨率”，设置列数、行数（分别 1–8，最多 64 格），选择画布分辨率。间距和留白单位为像素；留白同时用于画布外缘和格内图案边距。收起面板只影响显示，不修改工程，也不占用撤销步骤。
3. 点击预览中的任意格子，在左侧选择标牌类型、输入内容、调整箭头和尺寸。不同格子可以使用不同类型；空格保留为透明区域。
4. 右键源格子选择“复制标牌”，再右键目标格选择“粘贴标牌”；也可点击源格按 Ctrl+C，再点目标格按 Ctrl+V，或使用侧栏底部按钮。完整复制内容、类型、尺寸、独立颜色和组合牌分段，随后可单独修改编号。目标格已有标牌会被替换，边界和合并区域保留，合并中隐藏的其他格内容不变。各份副本互不影响；空白格不能复制；“清空此格”只清除选中格。复制缓存在当前工程编辑期间有效，不写入系统剪贴板。
5. 增减行列时会重新均分网格，取消合并和边界调整，全部标牌内容（包括合并中暂存的内容）按原槽位编号保留。缩小网格若会丢失已有内容，程序会保留原排列并提示先清空超出的槽位。
6. PNG 模式导出整张 PNG；X-Plane 模式可另导出 PNG + POL 或 SVG，使用当前设定的精确画布宽高。预览网格、编号、选中框和字高提示不导出。

所有素材共用一个拼图。关闭拼图窗口即退出程序，跨次编辑请保存工程。槽位间按各自的物理宽高比独立适配，图案居中、不拉伸；各格的 px/m 可以不同，适合分别分配 UV。制作模型时使用各块自身的毫米尺寸。

## 预览缩放

- 预览区滚轮以鼠标位置为中心缩放；底部“− / +”以窗口中心缩放。手动范围为 1%–800%。
- “适合窗口”完整显示画布，并随窗口大小重新适配；“100%”按一个贴图像素对应一个预览像素显示。
- 放大后按住中键拖动，或让预览获得焦点后按空格加左键拖动。平移不会移动标牌或分隔线。
- “视图”菜单提供相同操作；Ctrl++ / Ctrl+− 放大缩小，Ctrl+0 适合窗口，Ctrl+1 为 100%。
- 缩放和平移是当前会话的显示状态，不占用撤销、不修改工程和导出。读取另一工程时恢复适合窗口。矢量实时重绘；磨损预览按缩放提高采样，最长边上限 4096 px，导出始终使用工程原分辨率。

## X-Plane 模式

“X-Plane → 启用 X-Plane”控制是否显示 POL 相关操作。关闭时只有 PNG 图像导出；开启时“文件”菜单增加 PNG + POL 和 SVG，X-Plane 菜单显示 POL 设置，右上角主按钮改为 PNG + POL。没有有效标牌时导出与 POL 设置不可用。

开关随 `.assproj` 保存，也支持撤销和重做。关闭不会清除名称、layer、边界模式或出血。旧版工程缺少开关字段时自动开启，以保留原有工作方式；新工程默认关闭。

## 撤销与重做

- “编辑 → 撤销 / 重做”，或 Ctrl+Z / Ctrl+Y。主界面的输入框及组合牌表格内也使用工程历史。
- 支持标牌编辑、粘贴、清空、合并、拆分、恢复均分、拖动边界、行列和画布参数、颜色、油漆及 POL 设置。隐藏格和嵌套合并一并恢复。
- 一次连续边界拖动只算一步；Esc 取消拖动不产生记录。一次颜色窗口的修改作为一步，取消恢复原色且不产生记录。
- 保留最近 100 步。撤销后发生新修改会清除重做分支；选择区域、复制、保存和没有实际变化的操作不产生记录。
- 历史仅在当前编辑会话中保留，读取工程会清空历史。工程保存、导出的文件本身不随撤销回滚；撤销到与最近保存内容一致时，退出不会误报未保存。

## 保存与读取工程

1. 在“文件”菜单点击“保存工程”，保存为 `.assproj` 文件；“另存为…”可另建一个副本。下次启动程序，通过“文件 → 读取工程…”选择它。
2. 工程保存每个格子的类型、内容、字高、箭头、背景、边框、自由尺寸、组合牌分段、经纬度文本及独立颜色；同时保存行列、合并层级及隐藏格内容、调整后的边界、画布分辨率、间距、留白、参考字高、统一颜色、总 POL 名称、layer / 偏移、POL 边界模式、出血 px 及全部油漆参数。旧工程的逐格名称保留在工程数据中，生成总 POL 时不使用。
3. 读取后仍可点选、修改、拖动边界或逐层拆分合并区。工程不依赖导出的 PNG，也不需要安装字体。未完成的文字、过小的尺寸等制作草稿可以先保存，导出前再修正。
4. 读取另一个工程或退出整个程序时，有未保存修改会提醒保存；选择“取消”继续编辑。损坏或不支持的工程会提示错误，保留当前工程。没有自动保存，请主动保存重要进度。
5. 拼图窗口支持 **Ctrl+S 保存、Ctrl+Shift+S 另存、Ctrl+O 读取**。预览区获得焦点时还支持 **Ctrl+C 复制标牌、Ctrl+V 粘贴标牌**；输入框和表格编辑文字时不截获这些快捷键。

## 四色配色与单格覆盖

1. “标牌 → 标牌配色…”只显示 **黄色、黑色、白色、红色**。点击对应色块打开 PS 风格拾色器，支持 HSB / RGB / Hex；拼图实时预览。
2. 按图案的原始颜色分类：改黄色会同时影响黄字、黄底、黄边和黄色箭头，所有标牌类型及组合牌分段共用。颜色映射只执行一次，例如黄改黑、黑改白不会连锁替换。
3. 单格“当前标牌颜色…”仍可按文字 / 箭头、底色、边框覆盖。优先级为 **单格覆盖 → 四色映射 → 旧类型配色 → 旧通用配色 → 原始色**。恢复单格继承后重新使用全局配色。
4. 每行“重置”清除该色映射；“恢复默认”清除整套全局配色，包括旧类型 / 通用设置，单格覆盖保留。未改四色时，旧工程保持原外观。
5. 拾色器取消恢复本次选色；外层取消恢复打开时的整套配色。确认本轮配色只产生一个撤销步骤；颜色随 `.assproj` 保存。
6. 预览、PNG、SVG 使用同一配色，不改变图案尺寸、透明区域或 POL 分区。油漆纹理仍生效；改色部分不会被“参考暖黄”覆盖，未改的原始黄色保留原油漆行为。

## 配色预设

- “保存预设…”将整套配色写入 `.asscolors`，文件名作为名称；“读取预设…”可跨工程复用。预设不包含某个格子的覆盖、标牌文字或布局。
- 新预设使用 v2 格式，可读取 v3.16 的 v1 预设。旧类型 / 通用配色数据为兼容保留；确认新颜色后按四色映射优先取色。
- 载入立即预览，确认后保留或取消恢复；工程内含配色数据，不依赖预设文件路径。预设文件是可选的，程序仍只需一个 EXE。已保存的预设文件不随撤销或取消窗口删除。

## 油漆脏污与磨损

1. 在“标牌”菜单点击“油漆 / 磨损…”，选择 **参考轻污渍**，即本版与提供的 PSD 对应的默认材质：暖黄色薄漆、顺向细刷纹、微颗粒和轻污渍，默认不掉漆。另外有积尘污斑、轻微掉漆、短促擦磨三套预设。
2. 可独立调整污渍、剥落 / 擦磨、粉化褪色、刷纹 / 颗粒强度（各 0–100%）、纹理大小（25–400%）、随机种子和刷纹方向（0–180°，90°纵向）。左侧参数可滚动查看。修改后预览自动更新；“应用到拼图”保存修改，取消则保留原参数。
3. “使用参考暖黄 #FFAB09”沿用 PSD 的黄色漆面色调，只影响黄色区域；取消勾选保留原标志的黄色。黑、白、红色区域仍保留各自的颜色并应用刷纹。该颜色是用户样例的制作色，不代表规范材料色度。
4. 刷纹和颗粒数据来自 PSD；颜色部分按原图层的正常、柔光、叠加、滤色、正片叠底方式组合。污渍强度 35% 对应主参考的轻污渍层强度。磨损蒙版来自同目录 `Markings_01_轻微透明磨损Sample.psd`，只在增加磨损时从 alpha 通道削减油漆。两个原 PSD 均未改动。
5. 所有材质数据内置于 EXE，使用时无需 PSD、Photoshop、Python、网络或外部贴图。当前整张拼图统一应用参数，每个区域使用不同纹理偏移；相同内容、布局、参数和版本可重复导出。纹理大小相对字高；方向改变刷纹及污渍的方向。
6. “导出 PNG”和 POL 窗口的“导出 PNG + POL…”都会烘焙材质；预览灰底不导出，SVG 仍为干净轮廓。单块标牌使用 1 × 1 拼图。POL 按选定边界模式计算；实际图案模式使用完整图案外沿加出血，不因局部磨损收缩。
7. 工程保存全部油漆参数，包括新增的刷纹强度与暖黄开关。旧工程没有油漆设置时仍默认关闭；v3.6 工程保留已有数值，缺少的新字段采用刷纹 100% / 参考暖黄。新版采用 PSD 材质渲染，外观会与 v3.6 改变。

程序包的“PSD油漆示例”包含四套可继续编辑的工程和对应 2K PNG + POL；“PSD参考与程序对照.png”左侧是用户 PSD 的合成预览，右侧为程序导出的 A1 透明贴图置于同一灰底。灰底不属于输出素材。预览画布会缩小，细节以最终 PNG 为准。

## 自动生成 POL

1. 设置好拼图，先启用 X-Plane 模式，再点击右上角“PNG + POL…”或“X-Plane → POL 设置…”。填写总 POL 名称、`layer` 及偏移（−5 到 5）。默认 `markings 1`；可选 terrain、beaches、shoulders、taxiways、runways、markings、airports、roads、objects、light_objects、cars。
2. 只填写一个总名称，使用英文字母、数字、下划线或短横线，最多 60 字符，不填扩展名。在“分区边界”选择 **实际图案边界（含出血）** 或 **分割区域边界（含格内留白）**。实际图案模式使用字形、底板、边框的外接矩形，并在每侧外扩“出血 px”（默认 2，可调 0–32，限制在所在格内）；分割模式使用预览网格的区域边框，包含格内留白，跟随合并及边界拖动，不包含区域之间的间距。分割模式下出血输入暂时停用，切回实际图案模式会保留原值。表格即时显示所选模式的分区尺寸。“应用设置”保留设置并返回拼图，保存工程后下次可继续使用。
3. 点击“导出 PNG + POL…”并选择输出文件夹，直接生成 **一个 `名称.pol` 和一张 `名称_atlas.png`**，油漆效果已烘焙。工程请通过“保存工程”单独保存；导出素材不会额外写入工程、说明或 ZIP。同名文件存在时会询问覆盖，写入失败会尝试恢复原来的文件组。总 POL 为每个非空可见区域写入一条 `#subtex` 分区；**合并区算一个分区，空格及合并后隐藏的格子不写入。** 恢复拆分后再导出，会按恢复的区域更新分区。两种边界模式都使用矩形分区，字形孔洞及箭头旁的透明角仍在矩形内；切换模式只改变 POL 分区与对应物理尺寸，不改变 PNG 像素。
4. 将 PNG 与 POL 放在 X-Plane 地景包内同一文件夹，保持文件名与相对位置。在 WED 中选择这个总 POL，在资源预览中点击所需分区、启用 **Use Texture Map** 后放置。

`#subtex` 是 WED 的子图选择信息，模拟器本身不会据此自动裁切；直接用普通多边形而未选择子图，可能显示整张拼图。总 POL 只有一个 `SCALE`，以编号最前的非空区域的像素密度换算整张纹理的参考尺寸；各分区按所选边界计算的物理尺寸分别写在注释里。不同区域可有不同 px/m，使用 UV 映射放置时，实际大小由 WED / DSF 中的多边形范围决定。POL 始终贴地；立牌贴图要竖立仍需贴到 OBJ 模型，本功能不生成牌体、地理位置或 DSF。

格式依据：[POL 格式](https://developer.x-plane.com/?article=draped-polygon-polfac-file-format-specification)、[WED 手册](https://developer.x-plane.com/manuals/wed/)、[WED 子图解析代码](https://github.com/X-Plane/xptools/blob/master/src/WEDCore/WED_ResourceMgr.cpp)。已检查导出文件和坐标；当前版本未进行桌面交互或 WED / X-Plane 验收。

## 合并格子与调整边界

1. 先单击要保留显示内容的格子，它会成为左上角提示的“主选区域”。勾选“多选”，再点击其他相邻区域；也可按住 Ctrl 点选，或按住 Shift 点选另一角以选择矩形范围。
2. 点击“合并选区”。所选区域必须完整拼成一个矩形，支持横向、纵向和多行多列合并。合并区显示主选区域的标牌；其余格子的内容暂存，既不渲染也不参与密度计算。
3. 取消多选，移动鼠标到预览中的分隔线或青色方形手柄，出现横向/纵向双箭头后拖动。局部分界会调整相邻区域，上下行不必同宽；遇到一个大区与多个小区相邻时，相关的小区边界一起移动，以保持矩形且不重叠。画布外边界保持固定。
4. 拖动时图案保持比例，密度提示和建议分辨率实时更新；区域过窄时会限制继续拖动。按 Esc 可取消正在进行的这次拖动。
5. 选中合并区，点击“拆分合并区”，恢复上一层区域和各自内容；原合并区调整过大小时，子区域按原比例恢复。嵌套合并可以逐层拆分。区域过小、拆分后无法容纳留白时，会提示先拉大区域、提高分辨率或减小留白。
6. “恢复均分”会取消所有合并和边界调整，恢复当前行列数的均匀网格，同时恢复所有暂存的标牌。复制/粘贴只复制标牌参数，不复制合并结构。

合并区域里修改或清空当前标牌，只影响主选区域原来保存的内容；其他暂存格子仍会在拆分时恢复。分辨率变化会保留区域的相对边界，像素间距和留白保持设定值。

## 分辨率和密度参考

- 预设：1K（1024²）、2K（2048²）、4K（4096²）、8K（8192²）、2048×1024、4096×2048。宽高均可自定义为 128–8192 px，不强制取 2 的幂。
- 选中一格后，下方显示该图案实际占用的像素宽高、px/m、主字高和最小字高。最小字高计入机位牌经纬度小字和 MAX SPAN 的小写米单位。
- 默认“参考最小字高”为 **128 px**，可改为 16–1024 px。64 / 128 / 256 px 仅作为较低 / 常用 / 较高细节的制作参考，不是规范要求或模拟器清晰度保证；实际效果还取决于观看距离、UV 和 mipmap。
- 低于参考值的格子显示字高提醒，不强制阻止导出。“采用建议分辨率”按当前行列、间距、留白和所有已设置标牌计算，在保留画布宽高比的前提下选择可满足参考字高的最小档位（长边 512 / 1024 / 2048 / 4096 / 8192）。8K 仍不足时会提示减少槽位或拆分贴图。

## 新增地面类型

- MAX SPAN：输入翼展数值，例如 `36`、`65.5`；自动生成两行，米单位为小写 `m`。4 m 字高的默认整体高度为 9.5 m。可选黑色或透明背景与黄色边框。
- HP：输入 `4` 或 `HP4`，输出 `HP4`，黑底黄字。
- NO ENTRY：固定文字，红底白字；可调整字高、底板尺寸、边框。
- 机型文字：例如 `A320/B737`，黄色文字，可选黑底或透明；默认字高 300 mm，可调整。此项生成文字贴图，不包含停止线或机位引导线。

## 贴图与尺寸

- PNG 是 RGBA 文件。预览中的棋盘、道面、尺寸线、网格均不导出。黄色、黑色、红色底板属于标志本身，会保留。
- 单块标牌也通过拼图导出，设为 1 × 1 即可；透明留白、画布分辨率和物理尺寸的处理与多格相同。
- 拼图导出：PNG 与 SVG 都精确使用设定的画布宽高，间距和留白已经包含在画布内，不额外添加边缘。各格独立等比缩放，不以整张图的单一物理尺寸表示。
- SVG 为全路径轮廓和偶奇填充，不依赖系统字体。拼图 SVG 使用像素尺寸，与拼图 PNG 的布局一致。
- PNG 可导出干净或带油漆磨损的颜色贴图，并可附带总 POL；SVG 保留干净轮廓。DDS/mipmap、LIT、模型和地理放置文件未包含。
