## 标牌长宽比

在左侧「自由尺寸」切换到「长宽比」，输入 `3:2` 或 `1:2` 等比例。程序从自动尺寸补宽或补高，保留字形大小。组合牌使用整体长宽比，预览下方显示计算后的毫米尺寸。

比例随工程和格子复制保存，支持撤销与重做。留空使用自动尺寸，切回毫米模式可以继续使用原有宽高值。
