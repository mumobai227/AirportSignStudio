## 连续预览、机位过滤与自动分图

- 多张拼图在同一个预览中连续纵向排列，并分别显示边框和页号。滚轮浏览，Ctrl 加滚轮缩放，点选任意页面的格子即可编辑。
- 批量生成按分辨率、留白、标牌尺寸和参考字高自动选择网格并分页。可先填已有拼图中合适的空格。
- PDF 导入以机位坐标表的编号为准。打开命名规范的普通平面图时可使用同目录的同机场 0P 表。AutoCharts 在缺少正式坐标表时只导入已关联机位引入线的候选。

发布包包含 Windows x64 单文件 EXE、Windows ZIP、源码 ZIP 和 SHA256 校验文件。

8,332 项无窗口检查通过。虹桥、浦东、深圳、邯郸共 877 个正式机位编号与上一版核对结果一致。虹桥平面图同目录有 0P 时可读出 161 个机位，单独导入该平面图时不会把图上普通标签加入清单。
