## 左右留边和整行整列调整

- 在标牌尺寸下方分别设置左、右留边，单位为毫米。填 `-1` 使用自动留边。组合牌每段应用同一设定。
- 勾选预览上方的“整行 / 整列”，拖动横线或竖线会移动同一直线上的各段。勾选状态可随时切换，调整后的布局随工程保存。
- 支持撤销和重做，整条分割线的一次拖动记为一步。

Windows 10 / 11 x64 可直接使用单文件 `AirportSignStudio.exe`。发布页同时提供 Windows ZIP、源码 ZIP 和 SHA256 校验文件。

8,300 项无窗口检查通过。原有 68 份 PNG、SVG 和 POL 文件与前一版本逐文件一致，两张字形检查图仅有 Arial 标签的个别像素不同。
